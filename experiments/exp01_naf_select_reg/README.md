# 实验1：NAF二维频率选择＋分段正则

状态：代码已实现，未在真实数据上训练，未验证指标增益。以实验0为唯一基线，从官方Hiera预训练初始化，不从历史分割权重微调。

## 研究问题与来源

假设：深层特征中有用信息与干扰并不简单等同于低频与高频。根据每张图像的频谱学习选择，并约束选择预算和频段倾向，可能优于旧版全频率缩放。
本实验验证这一假设，不宣称能直接复现时序论文的效果，也不把医学图像中的高频一律视为噪声。

来源：Hu et al., *Noise Adaptive Filtering Neural Network Under Multiscale Features*, IEEE TASE 22, 2025，DOI [10.1109/TASE.2025.3579694](https://doi.org/10.1109/TASE.2025.3579694)。
核对材料为13页PDF，SHA256=f67d4904456946e642a1d3d4c7a40d3398cc9dc692d7a5ed9d6d1d1c94dd58f3。
重点核对PDF第4页/印刷页17053公式(5)–(7)，第5页/17054公式(8)–(9)及算法1；不是整篇论文的新一轮实验复现报告。

| 原论文机制 | 实验1的借鉴与改动 |
|---|---|
| FFT，池化＋线性层＋sigmoid形成V，沿频率softmax形成选择概率 | 2D rFFT；通道平均幅值与二维频率坐标，经小型MLP、sigmoid与softmax形成每图频率概率；所有通道共享掩码 |
| 依据概率随机选择ceil(0.9M)个分量，再投影、补齐与IFFT | 确定性的可微软预算选择，保留非DC掩码总量的90%；保留原坐标及相位，不做频率线性投影；irFFT恢复 |
| 低/中/高频正则系数随尺度为1/n、1/n²、1/n³ | 使用相同系数形状，n取已有层级P3=3、P4=4，按二维归一化半径划分频段 |
| 对选择矩阵V施加L2约束 | 约束实际预算掩码g的加权平方均值，避免缩小所有V规避惩罚；这是明确的适配改动 |
| 多尺度交换融合＋GRU | 不迁移；继续使用原有U形解码器，无新增跨尺度交互 |

论文文字对高低频选择方向存在不一致；本实验以公式(7)的权重形状为依据，效果以消融检验，不从文字推导相反的先验。
时间卷积尺度与图像层级不是相同物理量，n=3/4是本项目的映射假设。90%来自原论文，其余二维适配参数是本次固定候选值，尚未调优。

## 固定方法流程

接入位置：Hiera输出 → 原RFB → **仅P3/P4的独立NAF** → 原up1/up2/up3与主/辅助分割头。
352输入时，P3/P4通常为22×22、11×11，各64通道。P1/P2不处理；两个NAF之间不传递特征。

对一个特征X，独立执行：

1. FP32 `Q=rfft2(X, norm=ortho)`；不在半精度上对11/22尺寸做cuFFT。输入输出尺寸和dtype保持。
2. 按通道平均|Q|，以非DC频率的加权平均幅值归一化，再取log1p；拼接|2fy|和2fx。MLP为3→16→1的1×1卷积、GELU与sigmoid，输出V∈(0,1)。
3. `p ∝ softmax(V / T)`，T=0.1。用rFFT频点的共轭重数w进行全频谱归一化。解出c，使`g=min(1,c*p)`且`sum(w*g)=0.9*sum(w)`；DC权重w=0，DC掩码固定1。通过排序确定饱和集合，在集合内解析求c，保留梯度。这里的90%是软权重预算，并非90%频点的二值保留率。
4. kx=0及偶数宽度Nyquist列的共轭ky位置共用同一实数掩码。重数w对边界列为1、内部列为2，预算不随奇偶尺寸发生偏移。
5. `filtered=irfft2(g*Q, s=(H,W), norm=ortho)`；`Y=X+alpha*(filtered-X)`。alpha为可学习的`0.25*sigmoid(a)`，初始化0.1。掩码初始均匀为0.9（DC为1），即非DC频率初始有效增益0.99；不是严格恒等初始化。零初始化选择器末层，使初始滤波无频段偏向。
6. 新增随机参数在CPU RNG隔离区初始化；原模型参数及后续全局CPU随机数流不被新增初始化消耗。两个模块共新增**164个可训练参数**，自动进入原decoder AdamW参数组，学习率仍1e-3。

残差频率响应为`1-alpha+alpha*g`，位于[0.75,1]，DC响应为1。这个模块能选择性衰减，不能任意放大频率。alpha可能学到接近0，这意味着模型倾向不用该处理，不应将其解释为成功去噪。

## 分段正则与损失

`rho=sqrt((2fy)^2+(2fx)^2)/sqrt(2)`，以1/3和2/3为界划分低/中/高频；这是径向三段，不是把rFFT数组按索引切三份，也不是三段包含相同数量频点。

```text
stage n = 3 or 4
coefficient(n, band) = 1/n, 1/n², 1/n³
R_n = weighted_mean_over_batch_and_nonDC_frequencies(coefficient * g²)
R = (R_3 + R_4)/2
L_train = L_structure_main + L_structure_D2 + L_structure_D3 + 0.001*R
```

固定频率预算使所有g不能同时趋于0，分段系数因此能影响各频段间的预算分配。
它倾向于让惩罚较弱的频段保留更多权重；但图像内容选择仍由分割任务梯度共同决定，不保证每张图都遵守单一排序。
平方均值与原论文L2记法/求和归约不等价，因此不照搬论文中1e-5或1e-4的系数，当前lambda=1e-3是待验证候选。
初始化时额外损失约1e-4量级，日志保留原始R与lambda，不能因指标不变就断定正则有效。

正则只加入训练反传。验证Loss、最佳Loss选择、最佳IoU选择和独立评估全部沿用实验0口径，不把正则混入验证指标。
没有改变原Structure损失、D2/D3监督、数据划分、增强、优化器、调度器、训练轮数或官方初始化。
