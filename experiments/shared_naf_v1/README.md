本模块处理二维网络特征，以确定性软预算替代随机硬采样，对实际掩码施加平方均值正则；不加入论文的多尺度交换融合、GRU或频谱线性投影。不是逐式复现。

## 单层方法与固定候选参数

1. FP32 rfft2，norm=ortho，保持原频率坐标与相位。
2. 通道平均幅值，以非DC频率的重数加权平均幅值归一化并log1p，拼接|2fy|和2fx。
3. 3→16→1的1×1卷积MLP（GELU、sigmoid）形成V；温度T=0.1的softmax形成频率概率。
4. g=min(1,c*p)，解析分配c使sum(w*g)=0.9*sum(w)。w为完整实数频谱的重数，内部列2、边界列1；DC权重0、g固定1。90%是软掩码总量，不是二值频点保留率或能量比例。
5. rFFT边界列的共轭ky位置使用一致的实数掩码。irfft2明确指定原H/W，支持奇偶尺寸。
6. Y=X+alpha*(filtered-X)，alpha=0.25*sigmoid(a)，初始0.1。选择器末层零初始化，初始非DC g=0.9，有效增益0.99；不是严格恒等初始化。每层82参数。

新增模块在CPU RNG隔离区初始化，不改变原解码器参数或后续CPU随机数状态。禁用层的初始化不会改变保留模块的初始参数。
该模块仅衰减频率，响应在[0.75,1]；DC保持空间均值，但不保证边界不变。alpha接近0表示接近关闭，不能解释成成功筛选。
没有分辨率大小绑定的可学习频谱矩阵，但不声称严格的物理尺度不变性。参数少不代表FFT/排序的实际耗时可忽略。

## 正则归约：全部实验固定分母4

归一化半径rho=sqrt((2fy)^2+(2fx)^2)/sqrt(2)，以1/3、2/3分为低中高频。各段不是等数量频点。

| 固定层级n | 低频系数 | 中频系数 | 高频系数 |
|---|---:|---:|---:|
| P1=1 | 1 | 1 | 1 |
| P2=2 | 1/2 | 1/4 | 1/8 |
| P3=3 | 1/3 | 1/9 | 1/27 |
| P4=4 | 1/4 | 1/16 | 1/64 |

对每个启用层n，先在batch和非DC频率上取重数加权均值：

```text
R_n = sum_b,sum_f [w_f * coefficient(n,band_f) * g_bf²] / [B * sum_f w_f]
R = (sum_n_in_enabled R_n) / 4
L_train = L_structure_main + L_structure_D2 + L_structure_D3 + 0.001*R
```

每层贡献不受空间尺寸、batch大小或启用层数的额外放大；同一层在实验1/2/3的外部损失系数始终0.001/4。
关闭某层就是去掉该项，总正则通常会变小，不能声称各实验正则总量相同；保留层不会因只启用两层而翻倍。
P1三段系数相同，没有频段偏向；固定预算下其平方惩罚偏好均匀掩码，会抑制过度非均匀选择。
P2–P4对高频惩罚较弱，体现允许高频保留更多权重的先验，不可描述为重点惩罚高频。
正则只加入训练；验证Loss与最佳IoU/最佳Loss选择沿用原口径。
日志启动时明确层级、lambda和归约；每epoch按层记录三段掩码均值、alpha、原始R_n、选择标准差和保留预算。
原始Structure损失、辅助监督、数据、增强、优化器、学习率、调度、轮数和Hiera初始化均不改。

旧exp01_naf_select_reg（73e38b8及之前）仅P3/P4且使用(R3+R4)/2，不能当作现在实验1或实验2的新协议结果。本次使用新run_id前缀，不覆盖、不删除、不重命名旧输出。
