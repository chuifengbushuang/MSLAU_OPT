# 2026-10-20：NAF v1首轮12次实验结果

结论：本批次NAF均值均高于本批基线。四层三seed均改善、幅度较小；P1/P2平均最好，但两种部分层级配置均在seed2026下降，尚不能认定稳定超过baseline或层级排名已确定。

## 比较有效性与指标口径

12次均completed、每次恰好20个epoch、工作树干净、提交ef939ba、RTX3090物理GPU2；environment.txt逐字节相同，Python/torch/torchvision/CUDA/cuDNN运行记录一致。
官方Hiera初始化SHA、loader/loss及split源码哈希一致，三种NAF配置使用相同补丁和模块源码。常规训练/评估参数相同，只改变NAF接入层级。
三个历史名称checkpoint均有记录；本地没有权重，未检查其实际内容或逐图预测。
用户偏好的后续默认卡为0，本批实际记录为2；本批12次用同一卡，不据此要求重跑。

主表IoU来自训练结束保存的6位小数best val IoU。独立评估日志与其差异均小于1e-4，Dice/Precision/Recall只能获取4位小数的已打印值。
±为三个seed间样本标准差（n-1），不是120张验证图像的标准差；所有checkpoint由相同验证集挑选，独立评估仍在该验证集，不是外部测试。
同seed并不保证当前冻结Albumentations的逐次增强轨迹相同；不能将差值理解成只改变模块后的确定性因果效果。
