# 跨尺度直连退化与负beta1：代码、曲线及固定权重推理诊断

本轮仅分析已有实验，并在已有最佳checkpoint上临时改变beta做纯推理。没有训练模式、反向传播、优化器更新或checkpoint写入；参数在内存中恢复，原训练结果未覆盖。推理复现原始IoU0.856671427。

## 1. 曲线支持的结论

| 项目 | 原NAF替换版 | 跨尺度直连版 |
|---|---:|---:|
| 最佳验证IoU | 0.861666300 | 0.856671427 |
| 末5轮验证IoU均值 | 0.859946155 | 0.852304102 |
| 末5轮验证IoU样本SD | 0.002080449 | 0.005565980 |
| 第20轮训练主Structure loss | 0.284812448 | 0.286031699 |
| 第20轮验证主Structure loss | 0.353692766 | 0.342154279 |
| 最佳checkpoint Precision | 0.914768246 | 0.904615098 |
| 最佳checkpoint Recall | 0.935982995 | 0.939721714 |

两者训练loss接近，梯度smoke正常，跨尺度版也持续收敛，没有观察到梯度断裂或数值发散。跨尺度版验证软Structure loss反而较低，但阈值0.5的IoU较低：软损失和离散指标存在差异，Precision下降、Recall略升。它不是简单的模型完全学不动。

跨尺度版第6轮验证IoU从0.831019骤降到0.733146，第7轮恢复至0.832815；同期训练主loss继续从0.419803降至0.389359、0.383583。beta1相应为-0.070941/-0.077826/-0.084742，变化平滑，没有对应的beta爆炸。RFB中有BatchNorm、NAF训练/评估选择方式不同，可能使验证对分布变化敏感，但现有记录不足以把这一轮波动归因于BN或某个算子。末5轮SD包含学习趋势，不能当成跨seed稳定性证据。

## 2. 代码中的结构区别

原NAFi分支对local/context分别做独立的64→64投影，滤波后逐通道融合，再经过输出投影加回Pi。新增直连仅做bilinear上采样和单个beta乘法，绕过这些投影、频率选择和融合门控，直接在当前层坐标中相加。相邻RFB的64通道由不同卷积独立学习，通道数量相同并不保证语义基和尺度对齐。

原Decoder的UpBlock则在拼接后使用两层3×3卷积、BN和ReLU；新增三条直接相加并未恢复其空间整合能力。主输出端最直接：D1相加后立刻进入1×1主头，没有后续3×3精炼。

已有最佳权重的真实验证特征测得：NAF1上采样context相对于local的逐图RMS比平均约2.304；beta1直连相对于NAF1相加前输出的RMS比平均约11.24%。因此beta绝对值约0.1并不等于10%能量或小到无影响。尺度不一致是测量事实；“通道未校准导致退化”仍是结构假设，需要下一组有控制的实验检验。

## 3. beta1为什么能为负

beta是无约束nn.Parameter，没有sigmoid或非负限制。beta1只进入最后一级D1，直接受主Structure损失影响；D2/D3辅助头和NAF评分正则不直接依赖beta1。beta2/3则还影响后续NAF及多个头，优化信号不同。

固定其他参数时，记U=Up(D2)，D1=A1+beta1*U，则：

```text
dL/dbeta1 = sum(dL_main/dD1 * U)
main_logits = resize(W_head*A1 + bias + beta1*W_head*U)
```

beta1的符号由任务梯度与U的内积决定，不是模型将其当作概率。负beta只表示减去一个特征向量；由于主头W_head同时有正负权重，不能据此说“减弱前景”或“上层特征都是坏的”。AdamW weight_decay将已有参数向0收缩，也不能解释从0变成负数的方向。

记录还表明它并非从第一步就拒绝直连：初始beta1梯度-0.04986149，首次AdamW更新朝正方向；第3步前beta1仍约+0.001885，但第一轮结束已为-0.023735，随后逐渐到-0.107308。这是联合训练中的方向变化，不是零初始化导致无法学习。

## 4. 纯推理干预给出的更强证据

固定同一已训练checkpoint、beta2/3和所有其他权重，120张原验证图像、相同BF16/阈值/预处理：

| 仅改变beta1 | 验证IoU | 主Structure loss |
|---|---:|---:|
| 学到的-0.1073076 | 0.856671427 | 0.342154279 |
| 0 | 0.856953168 | 0.342511438 |
| +0.1073076 | 0.857207440 | 0.343639889 |

负值对应较低的软损失，但不对应较高的阈值IoU。翻正只改善0.0536个百分点，远小于新旧替换版0.4995个百分点的差距。把所有beta置0，IoU为0.856123754，依然不能恢复单独训练旧替换版的0.861666300；各分支已经联合适配，事后关掉直连不等价于从头训练不含直连的模型。

通过1×1主头对beta1路径做线性分解（不含bias，FP32计算，忽略最终BF16舍入），该负beta项平均给GT前景logit增加0.301790，给背景减少0.318285；约94.75%的前景像素该项为正，约96.47%的背景像素该项为负。其符号确实在当前主头坐标下提供了前景/背景分离方向；这并不保证边界像素或0.5阈值指标更好，也不构成具体语义病因定位。

这些是固定权重敏感性检查，不是重新训练的消融，更不是在验证集选择beta后的新模型成绩。没有保存被干预的checkpoint。

## 5. 建议的单一下一步：归一化、投影后再加

从原NAF替换版出发，将本次裸跨尺度连接替换为：

```text
Ui = Up(D{i+1})
Ci = Conv1x1_64to64(GroupNorm_8groups_affineFalse(Ui))
Di = NAFi(Pi,D{i+1}) + beta_i*Ci
```

三层相同；原NAF、RFB、三头和所有训练超参数保留。GroupNorm控制输入尺度、避免为这条路径新增BN运行统计；1×1投影学习跨层通道对齐；beta仍为无约束标量并初始化0，不因负值就强制非负。投影bias=False、权重用非零的单位映射初始化，使beta=0时初始行为仍与原替换版一致；不能将beta和投影同时初始化为0，否则该分支一阶梯度会同时被乘成0。

该候选在旧替换版上增加3×4096+3=12,291个可训练参数（GN无affine参数）。先只改变这一个结构因素，不同时改损失、阈值、beta约束、频率选择或轮数。若以后获准实施，先smoke验证beta=0前向一致，beta第一步有梯度、投影在beta打开后有梯度，再与原替换版和裸直连版按同协议比较。它是验证“裸跨层相加是否缺少校准”的方案，尚无收益保证。
